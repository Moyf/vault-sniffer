# Vault Sniffer

Visualize your Obsidian vault's file distribution with an interactive SpaceSniffer-style treemap chart.

## Features

- Interactive treemap visualization of your vault
- Color-coded by file type
- Click to navigate through folders
- Filter by file type
- Real-time file size display

## Development

### Installation

```bash
npm install
```

### Build

```bash
npm run build
```

### Development

```bash
npm run dev
```

## Usage

1. Install the plugin in Obsidian
2. Click the ribbon icon or use the command palette to open the vault sniffer
3. Explore your vault's file distribution
